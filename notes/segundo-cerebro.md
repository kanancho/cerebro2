\# Segundo Cerebro



Sistema de organización de conocimiento basado en archivos Markdown planos + un archivo índice (CLAUDE.md).



\## Características

\- Un archivo = un tema

\- Carpetas semánticas: notes, people, projects

\- Compatible con Claude Code y otros agentes

\- Se sincroniza fácilmente con GitHub



\## Estructura principal

\- notes/ → conocimiento por temas

\- people/ → información de personas

\- projects/ → estado de proyectos

\- MEMORY.md, LEARNINGS.md, decisions.md → contexto permanente
